6 Chartagent Studio v0 — the spec editor, before there is a planner

Every screen in the UI canvas assumes a planner upstream. Studio v0 has none — it opens a Flint frame, binds it, renders it, saves it, and refreshes it at $0.00. 6a, 6b and 6c are three surfaces that disagree about what the primary object is: the document, the chart, or the pipeline. 6d is the refusal set all three share; 6e is refresh.

Locked 2026-08-24 on 6b — the generated vocabulary() form is the editor, and the JSON is a drawer over the same document rather than a second surface. 6c's answer is taken for data only: the source is a bound object at request time, never stored in the frame — the pipeline is not the home screen. 6a and 6c stay on this canvas as the record of what was rejected and why. 6d and 6e are locked as drawn.

PROTOTYPE — THROWAWAY. Numbers are drawn from ADR-0005 and ADR-0006; the data is invented.
